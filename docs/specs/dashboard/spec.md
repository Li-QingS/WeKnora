# 评测与成本可视化页面（课题三 WP7）Spec

> 状态：已批准（2026-09-02）
> 课题：腾讯犀牛鸟 · WeKnora 开源训练营 课题三「质量评测基线与成本可观测」
> 工作包：WP7 前端展示与演示收尾（WP1-WP5 已完成）

## 背景

WP1-WP5 已经完成后端能力与 API：

- 评测历史：`GET /api/v1/evaluation/runs`，包含状态、进度、指标、`config_hash`；
- 模型用量：`GET /api/v1/model-calls` 与 `GET /api/v1/model-calls/summary`；
- Embedding 缓存：`GET /api/v1/embedding-cache/stats`。

但目前这些能力在前端不可见（或只有最小的模型用量页），中期评审和最终演示缺少一个能直接打开讲解的入口。WP7 的目标是补一个最小但完整的可视化页面，不做复杂图表。

## 目标

- G1：从 Web 界面进入“评测中心”，看到历史评测运行列表。
- G2：单次运行可查看指标、进度、配置哈希与关键参数。
- G3：“模型用量”页展示模型调用汇总/明细，并新增 Embedding 缓存命中统计。
- G4：演示时能直观展示：评测结果、成本费用、缓存前后对比。
- G5：不新增后端能力，不改已有 API；只补前端 API 封装与页面。

## 功能需求

- **F1：评测中心入口。** 在设置页导航中新增“评测中心”：
  - 历史运行列表：任务 ID、数据集、状态、进度、创建时间；
  - 状态筛选（可选）：pending / running / success / failed / interrupted；
  - 点击某行可查看详情。

- **F2：评测详情。** 单次运行详情至少展示：
  - 12 项指标（检索 + 生成）；
  - `config_hash`、数据集 ID、样本数；
  - 模型快照与版本信息；
  - 失败/中断时显示 `err_msg`。

- **F3：模型用量页增强。** 在现有“模型用量”页上增加“Embedding 缓存”卡片：
  - 展示 `hits`、`misses`、`provider_calls`；
  - 缓存未开启或后端无数据时显示 `unknown`。

- **F4：前端 API 封装。**
  - `listEvaluationRuns(page, pageSize, status?)`；
  - `getEvaluationResult(taskId)`；
  - `getModelCallSummary()`、`listModelCalls()`、`getEmbeddingCacheStats()`。

- **F5：权限与角色。**
  - 评测中心 Viewer 可读；
  - 模型用量与缓存统计沿用 Admin；
  - 前端入口按 `settingsAccess.ts` 隐藏不可访问项。

- **F6：交互与展示约束。**
  - 页面使用表格/卡片，不引入图表库；
  - 状态与费用使用可读标签，未知费用显示 `unknown`；
  - 页面不需要新增独立路由，使用设置页 section 机制。

## 非功能需求

- **N1：兼容现有前端。** 不改动已有页面行为；新增页面遵循 Settings.vue 现有 section 模式。
- **N2：只读。** 页面不提供删除/修改评测或价格的操作，避免破坏只读演示边界。
- **N3：性能。** 历史列表分页加载；详情按需请求。
- **N4：可测试。** 前端 type-check/build 通过；API 封装可用真实服务验证。
- **N5：无后端改动。** WP7 不新增迁移、不新增 API、不改后端逻辑。

## 不做的事

- **不做复杂图表。** 趋势图、饼图、CI 可视化大屏不在本期。
- **不做评测发起按钮。** 发起评测继续走 CLI/API。
- **不做价格编辑页面。** 现有价格 API 只读展示，不接编辑表单。
- **不做独立大路由/大屏。** 只挂在设置页 section。
- **不做 i18n 全量补齐。** 中文标签可先写死，i18n 完善作为后续。

## 验收标准

- **AC1（对应 F1）：评测中心可见。** 设置页导航出现“评测中心”，打开后能加载历史评测列表。
- **AC2（对应 F2）：详情可用。** 点击任意成功运行，能看到 12 项指标、`config_hash`、数据集与模型信息。
- **AC3（对应 F3）：缓存统计可见。** “模型用量”页显示 Embedding 缓存 hits/misses/provider_calls；无数据时显示 unknown。
- **AC4（对应 F4）：API 封装可用。** 新增前端 API 函数与真实后端返回一致。
- **AC5（对应 F5）：权限正确。** Viewer 看不到模型用量/缓存统计入口；评测中心按角色可读。
- **AC6（对应 N2）：只读。** 页面无评测删除/修改操作，无价格编辑表单。
- **AC7（对应 N4/N5）：回归。** 前端 type-check/build 通过；后端测试不受影响。

## 已确认的取舍（需求澄清记录）

1. 页面挂在设置页 section，不新增复杂平台路由。
2. 评测中心 Viewer 可读，模型用量/缓存统计 Admin。
3. 不做发起评测按钮和图表，避免演示页变成完整产品。
4. 中文标签先写死，i18n 后补。
