## 端到端验证

### 1. 正常评测落库

- 发起：`POST /api/v1/evaluation`，`dataset_id=default`
- 结果：`status=2`（success），`finished=1/1`
- 数据库：`evaluation_runs` 记录完整，`config_hash` 与 `config_snapshot` 已写入
- 指标：retrieval 与 generation 共 12 项指标齐全
- 快照：包含数据集哈希、Embedding/KnowledgeQA 模型、应用版本与 git commit

### 2. 历史列表

- `GET /api/v1/evaluation/runs?page=1&page_size=10` 返回记录
- 列表项包含 ID、数据集、状态、进度、指标、`finished_at`、配置快照等

### 3. 重启中断

- 通过 API 创建评测后，插入一条 `status=1`（running）且心跳过期的记录
- 重启 Lite 服务
- 查询同 task_id 返回 `status=4`（interrupted）、`finished=2/5`
- `err_msg=interrupted by service restart`

### 4. 租户隔离

- 注册第二个用户（独立租户）
- B 租户查询 A 租户的 task_id：HTTP 404 `Evaluation task not found`
- B 租户调用 `/evaluation/runs`：`total=0`
