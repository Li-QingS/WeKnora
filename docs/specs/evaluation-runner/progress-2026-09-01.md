## 实现内容

### 服务端

- `dataset_id` 真正生效：`default` 加载 `dataset/samples`，其他合法 ID 加载 `dataset/<id>`，支持安全字符校验与路径穿越拒绝。
- 数据集校验：5 个 Parquet 文件 schema 与引用完整性检查。
- 确定性数据集 SHA-256：按主键排序后固定顺序序列化计算。
- `POST /evaluation` 新增可选 `embedding_id` 与 `params` 覆盖；服务端合并默认值并校验参数范围。
- `config_hash` 在创建时即包含数据集哈希、生效参数与模型快照，同一配置同一哈希。
- 数据集加载失败在创建运行前返回 HTTP 400，Runner 可据此返回配置错误退出码。

### SDK

- `client/evaluation.go` 对齐 WP1 真实 API：`EvaluationTask / EvaluationDetail / EvaluationRun`。
- 新增 `StartEvaluation` / `GetEvaluationResult` / `ListEvaluationRuns`，均带 httptest 单测。

### Runner

- 新增 `weknora eval run`：
  - `--config`、`--wait/--no-wait`、`--timeout`、`--interval`、`--report-dir`、`--task-id`、`--dry-run`；
  - 支持对已创建任务用 `--task-id` 继续轮询并生成报告；
  - 报告输出 `evaluation-result.json` + `evaluation-report.md`；
  - 退出码：0 成功、2 回归（WP3 预留）、3 配置/数据集错误、4 服务/模型不可用、5 运行失败/超时、130 中断。
- 根目录 `make eval-baseline CONFIG=...` 一条命令入口。
- 新增演示数据集 `dataset/demo`（15 个 QA 对）与生成器 `dataset/build_demo.go`。

## 端到端验证

### 1. 一条命令成功基线

```bash
WEKNORA_HOST=http://localhost:8080 \
WEKNORA_TOKEN=<token> \
make eval-baseline CONFIG=./evaluation/configs/default.yaml
```

结果：

- 退出码 0；
- `artifacts/evaluation/evaluation-result.json` 与 `evaluation-report.md` 生成；
- 数据库 `evaluation_runs` 中同一 run_id 的 `config_hash` 与报告一致；
- 数据集 `demo`，sample_count=15，快照哈希一致；
- 12 项指标齐全，`finished=15/15`；
- 报告含复现命令与版本签名，无 API Key/凭据。

### 2. 非等待 + task-id 续跑

```bash
weknora eval run --config ./evaluation/configs/default.yaml --no-wait
weknora eval run --task-id <task_id> --report-dir /tmp/eval-resume
```

结果：两次均退出码 0，第二次生成报告，`config_hash` 与首次运行一致。

### 3. 错误退出码

- 不存在的 `dataset_id`（服务端 400）：退出码 3；
- 服务不可达：退出码 4；
- 无效 chat 模型导致运行失败：退出码 5，且失败报告已生成。

### 4. 路径安全

`dataset_id=../escape` 被服务端拒绝，返回 HTTP 400，不读取仓库外目录。
