## 实现内容

### 缓存表与 Repository

- `embedding_cache_entries`：租户、模型、维度、文本 SHA-256、向量 JSON、命中计数。
- PG 000091 / SQLite 000016 迁移，SQLite 守卫测试同步到版本 16。
- Repository：Get / Set / IncrementHit，唯一约束 `(tenant_id, model_id, dimension, text_hash)`。

### cachedEmbedder

- 单条 `Embed`：命中直接返回，未命中调用模型并写缓存。
- `BatchEmbed`：逐条查缓存，只对未命中文本调用模型，按原顺序合并。
- `BatchEmbedWithPool`：直接走 pooler + 缓存包装器，保证子批次也命中缓存。
- 缓存包装器位于 cost wrapper 外层：命中时不调用 provider，也不在 WP4 台账中新增记录。

### 开关与统计

- 环境变量 `EMBEDDING_CACHE_ENABLED=true` 开启，默认关闭。
- `GET /api/v1/embedding-cache/stats` 返回 `hits`、`misses`、`provider_calls`。
- 缓存读写失败 fail-open，不影响模型调用。
