# Change 1 验证结果：稳定前缀不足

## 改造内容

`wiki_page_modify` 在共享 Source Context 与 `<page_metadata>` 之间增加
固定 `<task_scope>`，作为额外的稳定前缀。

## 改造后两次运行

| 运行 | wiki_page_modify calls | cache_read | cache_miss | 命中率 |

| 第六次（改造后） | 16 | 19968 | 157974 | 11.22% |

## 结论

- 改造前 `wiki_page_modify` 基线：8.08%-14.05%；
- 改造后：9.17%-11.22%；
- 两次结果仍落在原有波动范围内，没有出现明显提升；
- 说明新增的两句 `<task_scope>` 太短，不足以显著扩大稳定前缀。

## 下一步

需要把更大的固定指令块搬到 `<page_metadata>` 之前，而不是只加几句说明。

候选做法：

1. 把 User Prompt 中不依赖 `PageTitle / PageSlug` 的固定规则前置；
2. 页面相关规则改为引用 `<page_metadata>`，而不是把标题/slug 内联到规则文本；
3. 保留页面标题、已有内容、新增信息等真正可变内容在稳定前缀之后。
