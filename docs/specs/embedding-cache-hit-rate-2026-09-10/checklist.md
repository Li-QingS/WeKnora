# Embedding 缓存命中率优化 Checklist

- [x] 远端回退点指向优化前版本。
- [x] 规范化范围保守且有边界测试。
- [x] 旧缓存无需清空即可继续命中。
- [x] 租户、模型、维度和模型配置隔离不变。
- [x] Batch 顺序、重复输入和错误语义不变。
- [x] 并发等待者不会共享可变向量切片。
- [x] 缓存故障仍回退 Provider。
- [x] 页面能解释新增统计含义。
- [x] benchmark 达到 Spec 目标并生成结果文件。
- [x] 全仓测试、静态检查和构建通过。
- [x] 文档上传、重解析及重建索引计入 `document_index`，同一内容重复索引会提高该用途的复用次数。
- [x] Wiki 节点评测计入 `wiki_evaluation`，不会改变页面上的文档向量化复用率。
- [x] 未标记的旧调用仍计入总量并归入 `other`，现有统计 API 汇总字段保持兼容。
- [x] 页面明确说明文档向量化指标的包含范围、排除 Wiki 评测和 RAG 查询，以及服务重启清零的口径。
