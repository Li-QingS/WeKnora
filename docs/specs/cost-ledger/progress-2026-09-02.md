## 实现内容

### 台账与价格

- `model_call_records`：每次模型调用的租户、模型、类型、用途、状态、耗时、Token、cache、unit、费用、价格快照。
- `model_prices`：按租户 + 模型配置输入/输出/cache 价格与 unit 价格。
- PG 000089/000090 与 SQLite 000014/000015 迁移，SQLite 守卫测试同步到版本 15。

### 记账机制

- `internal/costledger` 提供全局 Recorder hook，镜像 Langfuse manager。
- Chat / Embedding / Rerank / VLM / ASR 五个模型包都加了 cost wrapper：
  - Chat 记录最终 Usage（含流式）；
  - Embedding 使用近似 Token；
  - Rerank 记录 documents unit；
  - VLM / ASR 记录 requests unit。
- 容器启动后安装真实 Recorder；未安装时记账 no-op，不影响模型调用。

### API 与页面

- `GET /api/v1/model-calls`：明细分页 + 模型/类型/状态/时间筛选。
- `GET /api/v1/model-calls/summary`：按模型聚合次数、成功/失败、Token、费用。
- `GET/PUT /api/v1/model-prices`：价格查询与写入。
- 前端新增“模型用量”设置页：汇总表 + 最近调用明细，费用为空显示 `unknown`。
